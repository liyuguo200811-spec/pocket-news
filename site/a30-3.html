就像 Windows 深入人心的「开始」菜单和任务栏那样，AI 聊天软件本身也有让人们熟悉的共同 UI 逻辑。如果你手机上有多款商业的 AI 聊天客户端，你会发现它们的界面基本大同小异： 看看 Kimi 和豆包的界面，是不是长得很像？

那么，咱们再来看看 Agora 的界面，这个布局和操作风格是不是更加给你一种「他乡遇故知」的感觉？ 相信这样的布局能让你也快速上手。正是因为 Agora 采用的 UI 逻辑经过了各大知名 AI 厂商的长期验证，会用 ChatGPT、豆包、Kimi 等 App 的朋友，初次接触 Agora 也完全不必再攀登另外一座「学习曲线」的山峰，为这款新软件付出额外的学习成本。

Agora 不会劝退你。 说是容易上手，不过，在打开 Agora 主界面之后先别急着发消息。 Agora 并不是开箱即用的，作为一款不绑定任何厂商的 LLM 聊天客户端，你需要手动配置 LLM 提供商与模型。 只需点击 UI 左上角的「Agora」按钮，打开「对话」面板，然后依次点击「设置 -> 提供商」，即可进入配置提供商的界面。
