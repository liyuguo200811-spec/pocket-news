小心 GitHub 上的《GTA 6》“PC 移植版”：不法分子可能借机传播恶意

IT之家　11-28 14:34　共2页

IT之家 11 月 28 日消息，《GTA 6》无疑是有史以来规模最大的游戏作品之一。随着主机玩家畅玩系列最新作，PC 玩家也迫切希望能够体验这款游戏，玩家社群因此掀起了制作 PC 移植版的热潮。与此同时，网络犯罪分子也盯上了这股需求，开始借机设下“下载陷阱”，向用户传播 ClickFix 等一系列恶意程序。

当地时间 27 日，据外媒 Neowin 报道，Bitdefender 研究人员近日在 GitHub 上发现了两个声称提供《GTA 6》Windows 版下载的代码仓库。其中一个宣称提供无需启动器的完整破解版，另一个则自称是社区制作的移植项目，声称能够通过转译层让主机版游戏在 PC 上运行。
