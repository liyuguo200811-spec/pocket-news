Claude Code 灵魂人物，开始反思 Vibe Coding 的未来了

爱范儿　11-27 11:49

2026-11-27 11:49Anthropic 最近真是流年不利。一边是顶着史上最大 IPO 的光环上市不到一周就破发，另一边是自家最能打的 Claude Code 团队，接连有核心成员转投竞争对手 OpenAI。昨天，Claude Code 核心工程师 Thariq Shihipar 正式官宣加入 OpenAI。

而就在刚刚，有海外网友直接贴脸发问，说真信安全 AI 就不会跳槽，说白了还是为了大包。对此，Thariq 回了一段体面的公关话术，表示自己信仰的是向上竞赛，一家独大对谁都没好处。把过去一周的时间线摊开来看，家人们就能体会到 Anthropic 股东此刻的心情有多复杂。

先看资本市场。北京时间 11 月 19 日晚间，Anthropic 在纳斯达克风风光光挂牌，发行价 83 美元。首日盘中最高冲到 115.1 美元，收盘大涨 17%，市场看多情绪一度拉满。不过，负责稳定股价的承销商摩根士丹利很早便全额行使了绿鞋期权，使 Anthropic 失去了一项潜在的股价支撑手段。

叠加市场情绪走弱，股价随后持续承压。
