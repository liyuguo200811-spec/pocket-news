Agora 内置了 8 家主流提供商的接入方式，既包括 Google、OpenAI、Anthropic、DeepSeek 这样的主流厂商，也包括第三方的 LLM 服务平台——Open Router。开发团队为这些平台做了良好的适配，无需配置过多的参数，只需添加 API Key 即可，剩下的工作由 Agora 来处理就好。

相信一些读者就用着至少其中一家的服务，点击相应的提供商并添加 API Key，你会发现 Agora 支持添加多个 API Key。这里考虑的是多用户、多账号、多环境的需求（例如，企业账号与个人账号区分开来），你可以添加不止一个 API Key 然后手动切换，日后随时可以增删和修改。

为了便于区分，Agora 还允许你为 API Key 指定「名称」（相当于备注），这样可以防止搞混，比人工分辨那一长串 API Key 要方便多了。 需要注意的是，Ollama 与其他提供商不同，作为一个本地部署的平台，你需要在 Ollama 提供商的设置界面中确认「基础 URL」（也就是 API URL）是否填写正确。

若要使用 Ollama，我个人建议你优先考虑在局域网中部署，这样可以节省设备资源，具体教程可以参阅官方文档。 Agora 自带的提供商显然不足以覆盖所有优秀的厂商，我常用的小米 MiMo 就没有提供。
