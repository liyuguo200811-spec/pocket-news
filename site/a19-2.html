微软 GitHub 于 11 月 24 日应游戏发行商 Take-Two 的要求，关闭了名为 Leonida 的《GTA 6》PC 移植项目网络，涉及 3007 个代码库。Take-Two 在版权通知中称，11 月 20 日有人在网上发现被盗的 Xbox Series 版文件，次日 Leonida 项目出现。

而时隔 2 天，微软官方 GitHub 账号在 X 平台发布推文，以“GTA 6 终于来了”作为开头，并抛出“改变游戏运行位置是否越过法律界限”的问题，该推文发布后不久被删除，GitHub 尚未说明原因。该媒体解读认为，这条推文的发布时间过于敏感，刚封完移植库，转头又推荐一款能把主机游戏转成 PC 程序的工具，外界很容易读出自相矛盾的意味。

而且在推文中，微软 GitHub 抛出“改变游戏运行位置是否越过法律界限”的问题，等于公开承认该工具处在版权的灰色地带。
