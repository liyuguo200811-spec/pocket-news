“GTA 6 终于来了”：微软 GitHub 力挺 PS5 转 PC 工具惹争议

IT之家　11-28 10:56　共2页

IT之家 11 月 28 日消息，科技媒体 Windows Latest 昨日（11 月 27 日）发布博文，报道称微软旗下代码托管平台 GitHub 陷入舆论漩涡，在应 Take-Two 要求关闭 3,007 个民间移植 PC 版《侠盗猎车手 VI》（GTA 6）仓库后 2 天，官方宣传开源工具 AnyPS5。

AnyPS5 是 GitHub 上的开源项目，目标是把 PS5 游戏的可执行文件重写成能在 Windows 和 Linux 上运行的程序。该项目于今年 8 月发布，IT之家发稿前访问已 Fork 超 6,100 个，Star 数量达到 6.28 万个。

根据项目动态，AnyPS5 已实现 18824/39519 个系统库函数，已实现函数占已声明函数的比例达到 47.63%，并成功解码 1,460 种所有 AMD RDNA 2 已声明指令形式，完成度达到 100%。
