南非开发者宣称独自开发操作系统 Impossible OS：兼容 Win32 和

IT之家　11-21 21:32

IT之家 11 月 21 日消息，从零开发一套操作系统，即使对经验丰富的工程团队而言也是一项艰巨任务，南非开发者兼企业家德里克 · 佩恩却选择独自承担这项工作。当地时间 20 日，据外媒 TechSpot 报道，佩恩近日公布了面向现代 x86-64 PC 的全新操作系统 ——Impossible OS，其设计借鉴 Windows 11，完全基于开源代码开发。

根据项目官方宣言，Impossible OS 的目标是原生运行基于 Win32 API 开发的软件，同时兼容 Linux 二进制程序。佩恩强调，其并非“又一个 Linux 发行版”，而是一套拥有自身底层架构的独立操作系统，包含 Ring 0 内核、UEFI 引导程序和桌面图形界面等核心组件。

在兼容性方面，Impossible OS 通过内核原生 API 实现对 Win32 软件的支持，并利用内置兼容层运行 Linux ELF 二进制程序。系统主体代码将由佩恩使用 C 语言和 x86-64 汇编编写，对于没有必要从零重写的部分，项目也会适当采用经过验证的成熟开源库。
