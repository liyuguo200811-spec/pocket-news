幸运的是，得益于 OpenAI 的巨大影响力，OpenAI 这家 AI 巨头的 API 规范（API schema）已经成为了业内的事实标准，因此无论是 MiMo 等大模型厂商，还是 llama.cpp 这样的基础设施，都至少提供了兼容 OpenAI 的服务端。

与此同时，Anthropic 和 Google 的 API 规范同样具有影响力，因此部分厂商也提供兼容。 Agora 作为 BYOK 的聊天工具，必然提供了自定义提供商的选项，可以让你使用兼容上述三家巨头 API 的提供商。

在「提供商」界面里往下滑，你就能见到「自定义提供商」的栏目，如下图所示。 点击「添加提供商」，选择提供商的兼容 API 类型（OpenAI / Anthropic / Google），然后填入提供商给你的地址与 API Key，即可完成配置。

你同样可以为每个提供商添加不止一个 API Key。 本地部署的 llama.cpp，可以借助「自定义提供商」在 Agora 中使用，这同时适用于局域网与手机上的部署6。只需把提供商的地址设为 llama.cpp 服务器（llama-serve）的地址即可。

在接下来的步骤中，Agora 就可以为 llama.cpp 用户带来绝佳的、不亚于大厂 App 的移动端 LLM 聊天体验。
