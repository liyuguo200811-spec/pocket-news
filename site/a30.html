App+1｜Agora：开源、易用、好用，给 Android 用户的 LLM 聊

少数派　11-26　共6页

我是大语言模型（LLM）的日常使用者，同时也是不止步于现有解决方案的「极客」。长期以来，Kimi、DeepSeek 等头部厂商提供的客户端都能满足我日常的聊天需求。但后来我了解到小米 MiMo v2.6 系列模型拥有同样强大的表现，还没有折磨人的「5小时限额」1，就决定试试。

结果这一试就让我爱上了 MiMo，享受 MiMo 的性能、回答质量与 Agent 表现，当然也爱上了（对当时的我来说）很新却很实用的方式——使用 API 远程调用大模型。 API 调用大模型作为一种相对成熟的用法，也催生了一套强大、稳定的 LLM 生态。

对我来说，最大的意义莫过于以此实现属于自己的 LLM 聊天体验：选择一款支持自定义配置的开源聊天工具，在聊天客户端中配置不同厂商的 API，就可以在同一个 App 中使用多家厂商的模型，还可以让你更好地掌控聊天过程和相关数据。

这是与各大厂商 AI 聊天应用相比截然不同的体验，还能弥补 MiMo 等部分厂商未提供官方聊天工具的不足2。 而在桌面端，成熟、支持 BYOK3 的开源聊天工具早已有之：ChatBox、Jan，开箱即用，还跨平台。支持 BYOK 的产品往往兼容 OpenAI、Anthropic 的 API，只要厂商提供与之相兼容的 API 接口，就可以轻松连接。
