# 口袋新闻 · 老年机极简版

给 128×160 / 240×320 老式功能机看的每日新闻站。
**零 JS、零 CSS 文件、零图片、零外链资源**，首页约 1.6KB，正文页约 1.7KB。

## 板块

| 板块 | 源 | 说明 |
|---|---|---|
| 要闻 | 中国新闻网（滚动 + 国内） | 时政为主，正文去文章页抓取 |
| 科技 | IT之家、量子位、极客公园 | 含 AI 圈动态 |
| 游戏 | 触乐、游研社、GameLook | 更新慢，窗口放宽到 72 小时 |
| 热榜 | 百度热搜 | 自带热度值，已过滤娱乐八卦 |

每条保留 **标题 + 最多 500 字正文**。不再放"原文"链接——一是百度热搜的原文是搜索结果页、
中新网和 IT之家的原文是现代网页，老年机都打不开；二是跳出去也没意义，内容已经抓进来了。

## 本地怎么跑

```powershell
cd D:\开发环境\nokia-news
```

## 三个踩过的坑

**1. 链接不能带 `.html`**
Cloudflare Pages 默认开 Pretty URLs，会把 `/a01.html` 用 **308** 重定向到 `/a01`。
308 是 2015 年才有的状态码，老年机浏览器不认识，直接报"解析错误"。
所以链接一律写成 `a01`、`list-2`、`cat-keji`，首页写成 `/`。
`build.py` 里加了检查：**页面里只要出现 `.html` 链接就构建失败**。

**2. 抓正文会混进垃圾**
中新网的 HTML 注释会漏出 `-->`，机核会抓成导航栏（"GPASS首页机组讨论资讯播客…"）。
现在做了三道防线：剥注释、按域名锁定正文容器、检测到导航词就丢弃这条。

**3. 机核不能用于自动抓取**
它的 RSS 和文章页会被阿里云 WAF 拦截（返回验证页），时好时坏，所以从源列表里移除了。

## 部署

1. Cloudflare → Workers & Pages → Create → Pages → **Upload assets**
2. 拖 `site` 文件夹，项目名 `pocket-news-4yu`
3. 更新时：Deployments → **Create deployment** → 再拖一次

自动更新：把项目推到 GitHub，Pages 改成连仓库，构建命令留空、输出目录填 `site`。
